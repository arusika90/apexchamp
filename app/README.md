# Предрагович — приложение (демо без сервера)

Кликабельная версия платформы: вход по ролям, кабинеты организатора, судьи и участника,
публичные результаты и дизайн-система. Подсчёт баллов, процентов, мест и Гран-при работает по-настоящему.
Данные хранятся в localStorage браузера, сервера и базы пока нет.

## Как запустить

Из папки проекта:

```bash
python3 -m http.server 5173 --directory app
```

Открыть http://localhost:5173. Нужен именно сервер: браузер не грузит модули с `file://`.

## Пароль на входе

Приложение закрыто простым паролем (файл `js/gate.js`). Проверка идёт в браузере, это защита от случайных
глаз, а не от взлома. Текущий пароль: `predragovic`. Чтобы сменить, положите в `gate.js` SHA-256 нового пароля:

```bash
printf 'новый пароль' | shasum -a 256
```

## Публикация

При каждом пуше в `main` GitHub Actions (`.github/workflows/pages.yml`) выкладывает папку `app` на GitHub Pages.
В настройках репозитория один раз выбрать Settings → Pages → Source: GitHub Actions.

## Страницы

| Адрес | Что там |
|---|---|
| `#/roles` | Выбор роли, выход, переключение этапа «судейство / итоги опубликованы», сброс демо-данных |
| `#/register` | Регистрация нового участника (имя, инстаграм, страна, почта, категория) |
| `#/design` | Библиотека дизайн-системы: цвета из токенов, типографика, все компоненты |
| `#/org` … | Организатор: обзор, номинации и критерии, судьи, участники, работа с правкой оценок, места и Гран-при |
| `#/judge` … | Судья: список своих работ, ведомость с баллами, штрафом, комментарием, отводом |
| `#/me` | Участник: свои работы, процент, место, оценки по группам, анонимные комментарии |
| `#/results` | Публичная таблица без имён, Гран-при, спец-призы, поиск по номеру |

## Устройство кода

| Файл | Что делает |
|---|---|
| `css/tokens.css` | Все цвета, радиусы, размеры шрифта. Поменять палитру — только здесь |
| `css/app.css` | Компоненты: кнопки, чипы, карточки, таблицы, баллы, адаптив |
| `js/data.js` | Демо-данные прошлого чемпионата и шаблоны критериев |
| `js/scoring.js` | Вся математика: процент, места по порогам или рейтингу, Гран-при, разброс |
| `js/store.js` | Состояние и сохранение в localStorage |
| `js/views/*.js` | Экраны по ролям |
| `js/app.js` | Роутер и обработка нажатий |

## Правила подсчёта, заложенные сейчас

- Процент работы = сумма баллов всех отправивших судей ÷ (число отправивших × максимум номинации).
- Места: по умолчанию пороги по категориям 70/65/60, 80/70/65, 85/80/72 %. В настройках можно переключить
  на рейтинг в категории или ручное назначение. Пороги предварительные, ждём ответа эксперта.
- Гран-при: сумма процентов трёх заявленных работ, следующие два — вице.
- Округление до сотых (ВК-303: 71,375 → 71,38 %). В старой таблице было обрезание, вопрос к эксперту.

## Что демо, а что настоящее

Настоящее: роли и доступы, регистрация участника и правка профиля, подсчёт, места, Гран-при, правка оценок организатором с историей, отвод судьи,
черновики, скрытие итогов до публикации, анонимность судей для участника.
Демо: фото работ (заглушки), PDF-дипломы, напоминания судьям, импорт из Excel, вход без пароля.
Баллы всех работ, кроме ВК-303, сгенерированы так, чтобы проценты были близки к прошлой ведомости.
