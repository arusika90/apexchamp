# Predragovic — платформа для судейства чемпионатов

Проект создан 23.10.2026. Материалы — в `materials/`, разбор и вопросы — в `notes/`,
кликабельное приложение без сервера — в `app/` (запуск: `python3 serve.py`).

## Что это

**Универсальная платформа**, на которой любой организатор создаёт свой чемпионат: задаёт номинации,
критерии и максимумы баллов, приглашает судей и участников, а система считает результаты и показывает
их каждому в своей роли. Первый чемпионат (и образец для настройки по умолчанию) — по наращиванию
и ламинированию ресниц и оформлению бровей:

- **судьи** заходят в свои ведомости, ставят баллы по критериям и пишут комментарий к каждой работе;
- **участники** видят оценки и комментарии судей по своим работам, а после оглашения — общую таблицу
  с процентами и призовыми местами;
- **организатор** видит и редактирует всё;
- система сама считает сумму баллов и средний процент по каждой работе.

Сейчас всё это делается вручную в Google Forms + Google Sheets (см. `materials/`).

## Структура папки

| Путь | Что там |
|---|---|
| `materials/ВК-303 (Ответы).xlsx` | Ответы судей из Google Forms по одной работе (ВК-303, брови краска) — пример судейской ведомости |
| `materials/Оценки_призовые места.xlsx` | Общая ведомость организатора: все номинации, ФИО, Instagram, страна, служебные пометки, спец-призы, Гран-при |
| `materials/Оценки_призовые места_гран-при (публичная).xlsx` | Та же ведомость в виде, который видят участники: только номер работы, средний балл, место, категория |
| `materials/screenshots/` | Скриншоты из переписки |
| `notes/01-требования.md` | Роли и правила подсчёта (со слов организатора) |
| `notes/02-данные-из-ведомостей.md` | Разбор структуры таблиц, номинаций, формулы, открытые вопросы |
| `notes/03-дизайн-референс.md` | Референс интерфейса — elementaree.ru: шрифт, цвета, скругления |
| `notes/04-практика-других-чемпионатов.md` | Как судят Star World, Perfection Champ, Звёздный стиль, Beauty Olymp, LASH.BOMBA: критерии, пороги, правила |
| `notes/05-вопросы-эксперту.md` | Список вопросов эксперту по судейству (10 главных + по темам), с вариантами ответов |
| `notes/06-конкуренты.md` | Чем пользуются организаторы сейчас, универсальные платформы РФ и международные, наше отличие |
| `materials/внешние-регламенты/` | Скачанные публичные документы «Звёздного стиля»: критерии, проходные баллы, регламент |
| `design/экраны-v1/` | Макеты семи экранов (организатор, судья, участник, публичные результаты) и ссылка на канвас |
| `app/` | **Рабочее приложение**: вход по ролям, кабинеты, подсчёт, публичные результаты, дизайн-система. Запуск — в `app/README.md` |
