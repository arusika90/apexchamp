# Конкуренты и аналоги

Собрано 23.10.2026 по открытым источникам. Три группы: чем пользуются сейчас организаторы
бьюти-чемпионатов, универсальные платформы для конкурсов (РФ) и международные платформы.

## 1. Как сейчас живут бьюти-чемпионаты (реальный конкурент — «ручной» стек)

| Организатор | Приём работ | Судейство | Результаты |
|---|---|---|---|
| Наш прошлый чемпионат | ссылки на Google Drive | Google Forms на каждую работу → Google Sheets | ручная сводная таблица + «обезличенная» копия |
| Звёздный стиль | папка на Яндекс.Диске, инструкция от менеджера в Telegram | судьи по направлению, Google Docs с критериями | Google Docs «проходные баллы», оглашение в соцсетях |
| Perfection Champ | по ссылке в профиле Instagram/Telegram | онлайн, 5–6 дней | прямой эфир |
| Beauty Olymp | «специализированная онлайн-платформа» (название не раскрыто) | судейская карточка с ID, баллами и комментарием | публикация на сайте, рейтинг |
| LASH.BOMBA | личный кабинет участника, Zoom | «электронное судейство», средний балл не менее 3 судей | оценочный лист участнику |

Вывод: специализированной платформы для бьюти-чемпионатов в открытом доступе **не найдено**. Крупные
организаторы либо собирают из Google-инструментов и Tilda, либо заказывают кабинет под себя
(LASH.BOMBA, Beauty Olymp). Ниша свободна.

## 2. Универсальные конкурсные платформы (РФ)

**ЦПК — Цифровой портал для проведения конкурсов** — https://cifraportal.ru/
- SaaS: роли организатор / член жюри / участник, личные кабинеты, галерея работ для жюри, оценка по критериям
  с комментариями, итоги и рейтинги в реальном времени, автогенерация сертификатов, белый лейбл сайта,
  российские серверы. 30 конкурсов, 20 тыс. заявок. Цена — по запросу (ООО «УИБ», Казань).
- Ближайший по функциям аналог. Нет бьюти-специфики: категорий по стажу, порогов по категориям, Гран-при,
  спец-призов, публичной обезличенной таблицы.

**Competizer** — https://intro.competizer.com/
- Конкурсы, премии, гранты, олимпиады. Жюри по шкале до максимума организатора или «да/нет/может быть»,
  слепое судейство, народное голосование. Страница из браузера не открылась (ограничение), описание по поиску.

**PrimeTime.today** — https://primetime.today/
- Фестивали и творческие конкурсы (танцы, вокал): заявки коллективов, программа выступлений, судьи ставят
  оценки онлайн, авторасчёт призёров, наградная продукция. Заточен под очные фестивали с расписанием.

**Compit** — https://compit.tech/ и **РобоСити** — https://robocity.info/org — автоматизация соревнований
(спорт, робототехника): заявки, протоколы, сертификаты.

Open source на GitHub: «КейсПортал» (Next.js + Supabase, слепое судейство, нормализация оценок,
мультиарендность) — https://github.com/parh0m2007/portalprojects ; простая платформа судейства —
https://github.com/hhhhhffd/platform_for_sudies. Полезны как пример модели данных, не как продукт.

## 3. Международные платформы (awards & judging software)

| Платформа | Что умеет | Цена |
|---|---|---|
| Award Force | приём заявок, онлайн-судейство, рубрики, калибровка судей, автоматический выбор победителей | по запросу, годовая |
| Submittable | приём и совместное судейство, рубрики, отчёты | по запросу |
| Evalato | заявки, назначение судей, шаблоны рубрик, матрица результатов | по запросу |
| Judgify | слепое судейство, live-скоринг, лидерборды, до 5 раундов на Pro | есть бесплатный уровень |
| OpenWater | абстракты, peer-судейство, скоринг | по запросу |
| ScoreJudge | судья получает приватную ссылку без аккаунта, веса критериев, лидерборд | есть бесплатный план |
| ContestPad / Launchpad6 | рейтинги 1–10, мультикритериальные рубрики, веса, среднее или сумма, исключение судей, не закончивших оценку | по запросу |

Все — англоязычные, ориентированы на корпоративные премии и гранты, цены «по запросу» и в долларах.
Для мастера ресниц из Беларуси или Азербайджана это не вариант.

Источники: https://gitnux.org/best/contest-judging-software/ , https://scorejudge.com/scorejudge-vs-judgify/ ,
https://www.launchpad6.com/online-judging-software , https://www.g2.com/compare/award-force-vs-awardstage-vs-judgify

## 4. Где наше отличие

1. **Шаблон бьюти-чемпионата из коробки**: номинации, критерии с максимумами, категории юниор/мастер/эксперт,
   пороги по категориям, Гран-при, спец-призы, обезличенная публичная таблица.
2. **Онлайн по фото**: чек-лист ракурсов, правило «нет ракурса — 0», комментарий судьи обязателен.
3. **Участник видит свой лист и комментарии** в кабинете, а не по запросу на почту.
4. Русский интерфейс + английский для участников из Европы и Кавказа; оплата из разных стран.
5. Цена, понятная организатору небольшого чемпионата, а не enterprise «по запросу».
