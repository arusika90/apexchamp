# Экраны системы, версия 1 (23.10.2026)

Канвас с макетами: https://claude.ai/artifact/SyZAH6nqkJNKFci9pp4nEB (приватная ссылка, открывается у владельца).
Здесь — исходники артбордов в формате .dc.html и индекс canvas.json, чтобы макеты не потерялись вместе с сессией.

| Файл | Экран |
|---|---|
| Main.dc.html | Организатор · панель чемпионата: этапы, цифры, прогресс по номинациям, «требует внимания» |
| Setup.dc.html | Организатор · конструктор номинации: критерии с максимумами, проверка суммы, пороги мест |
| JudgeList.dc.html | Судья · мои работы: только номера работ, статусы, отвод |
| Judge.dc.html | Судья · ведомость работы: фото, критерии кнопками-баллами, штраф, комментарий, итог |
| JudgeMobile.dc.html | Судья · та же ведомость на телефоне 390×844 |
| Participant.dc.html | Участник · мои работы: процент, место, оценки по группам, анонимные комментарии судей |
| Results.dc.html | Публичная страница результатов: номинации, таблица без имён, Гран-при, спец-призы, пороги |

Стиль: белые карточки на светло-сером, один жёлтый акцент (#FFDD2D) для главного действия, чёрные активные вкладки,
скругления 12–20 px, шрифт Inter. Акцент переключается на оранжевый elementaree (#ED5C1E) в настройках артборда.
